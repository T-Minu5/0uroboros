# UX, LookDev, and Design System

## Board
- `UX-BOARD-001` Five vertical Node columns.
- `UX-BOARD-002` Local player bottom, opponent top on each client.
- `UX-BOARD-003` Opponent cards → opponent Power/priority → central Location UI/text → local Power/priority → local cards/drop area. Vertical relationship.
- `UX-NODE-001` Drop area explicitly says Node number.
- `UX-NODE-002` Clear hover and valid/invalid target feedback.
- `UX-NODE-003` Communicate 4-slot capacity and remaining slots.
- `UX-NODE-004` Cards compact/reflow when one leaves.
- `UX-NODE-005` Priority uses color plus icon/arrow.
- `UX-NODE-006` Node Power is the presentation name for Node P1 Power and Node P2 Power. The Node center communicates Player A Power, Location, Player B Power vertically. This is presentation, not a new gameplay mechanic.

## Accessibility
- `UX-A11Y-001` Critical state never uses color alone.
- `UX-A11Y-002` Gameplay text/state remains readable during effects.

## Motion
- `LOOKDEV-PHASE-001` Animate phase, turn, and Node-opening announcements.
- `LOOKDEV-EFFECT-001` Effect animation communicates cause, target, magnitude, outcome.
- `LOOKDEV-COLLAPSE-001` Wave Collapse short but theatrical, with clear Node resolution, probability selection, selected Node, reward winner.
- `LOOKDEV-FX-001` Use roughly 3–4 configurable theatrics tiers.
- `LOOKDEV-FX-002` Magnitude maps to gameplay impact.
- `LOOKDEV-FX-003` Prefer reusable configurable effect primitives.
- `LOOKDEV-FX-004` Visuals consume authoritative events and never decide outcomes.
- `LOOKDEV-COLLAPSE-002` Promising bespoke direction: singularity/black-hole swell/collapse blended with liquid/wave interface treatment.
- `LOOKDEV-COLLAPSE-003` Keep Cyberpunk + Quantum Physics + Occult.
- `LOOKDEV-COLLAPSE-004` Camera direction open to agents subject to readability.

## Typography
- `DESIGN-TYPE-001` Inter: primary UI/card/Location/log/modal text. Thin, Regular, Medium, Bold and italics.
- `DESIGN-TYPE-002` Orbitron Regular: card titles, game titles, subtitles, large numerals.
- `DESIGN-TYPE-003` No casual third font.

## Colors
- `DESIGN-COLOR-001` Blue #4173F2; Light Blue #31A9FF; Cyan #27E2FF; Purple #BC64FF; Pink #FF0BA1; Red #FA0048; Gold #FFCC12; Green #1FFFB1; Black #030012.
- `DESIGN-COLOR-002` Derived tints/shades allowed.
- `DESIGN-COLOR-003` #030012 is darkest normal design color. Shadows and shaders may go darker.
- `DESIGN-COLOR-004` P1/P2 permanent colors not yet locked.

## Copy
- `DESIGN-COPY-001` Proper sentence case.
- `DESIGN-COPY-002` One-line labels/titles need no period. Effect text does.
- `DESIGN-COPY-003` Clear and concise.
- `DESIGN-COPY-004` No em dashes.
- `DESIGN-COPY-005` Bullets allowed for multiple effects.

## Logs
- `UX-LOG-001` Game/Draft logs inspectable, not dominant.
- `UX-LOG-002` Use P1/P2.
- `UX-LOG-003` Concise.
