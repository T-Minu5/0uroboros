# Effect combination plan

One visual grammar. Mechanics change. The language does not.

Shared rules:

- Cyan: local player / legal / active
- Gold: opponent
- Red: Drain / damage
- Green: Restore / heal
- Purple: probability / Collapse
- Quiet table unless a tier 2+ event is running

## Runtime

| Event | Tier | Combination | First pass |
| --- | --- | --- | --- |
| Cycle deal | 1 | Cards appear in the fan. No table flash. | Existing hand mount |
| Card deploy | 2 | Overlay flight, then settle | HUD overlay flight |
| Reveal | 2 | Flip + edge light. Then Effect plate | 3D flip + plate |
| Draw / +N Cards | 1 | New fan cards only. Log names the source | Source log added |
| Action / Crypto | 1 | Metric pop | Existing status pop |
| Drain | 2 | Source lift → red particle path → DC pylon hit | World-space tube + local `-N` |
| Restore | 2 | Source lift → cyan/green path → DC fill | World-space tube + local `+N` |
| Probability transfer | 2 | Purple filament Node→Node. Rings shrink/grow | 3D rings + path |
| Draw / +N Cards | 1 | Path from source to hand | HUD path |
| Action / Crypto | 1 | Path from source to Actions/Wallet | HUD path |

## Collapse

| Event | Tier | Combination | First pass |
| --- | --- | --- | --- |
| Collapse start | 4 | Board quiets. Title. | Overlay + dim |
| Node 1→5 | 3 | Figure Node. Location then cards then Power then reward, locally | Lane focus, no center checklist |
| Node winner | 3 | Larger Power emphasizes. Loser recedes | Unobstructed numbers |
| Weighted selection | 4 | Singularity field + ring lock | Table wave + purple ring |
| Circuit Reward | 3 | Reward name. Field settles | Overlay |
| Draft transition | 1 | Collapse overlay leaves. Draft plate | Existing barrier |

Do not implement the full catalog before this language is proven in play.
