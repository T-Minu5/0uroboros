# Product reset architecture (Astra)

Date: 2026-09-08

## Decision

**Retain** authoritative `src/game` + Vitest multi-Cycle proof.  
**Retain** presentation queue / Collapse script (already Node-by-Node).  
**Simplify** delivery harness: do not run the LIVE_OPENAI autonomous loop for this phase. Targeted specialist judgment only when needed.  
**Rebuild** client presentation for Snap sequencing + Hearthstone card weight without copying their skins.  
**Preserve** approved Node column, click=inspect, drag=deploy.

## Why

Previous V3 delivery spent API budget on critique loops while the UI remained HUD-congested and low-weight. Priority order puts playable Cycles and UX reset above harness elegance.

## Binding principles

1. **Snap sequencing:** one active event; cause before effect; beat between Nodes.  
2. **Hearthstone weight:** anticipation → contact → follow-through on card travel and local impact.  
3. **Theme firewall:** cyberpunk / quantum / occult first-party art only for palette and chrome.
