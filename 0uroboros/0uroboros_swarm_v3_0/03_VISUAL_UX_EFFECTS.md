# Visual / UX / effects production

## Presentation principle

Effects explain what the game did:

```text
SOURCE → ACTIVATION → PATH → TARGET → REACTION → RESULT
```

Global events announce globally. Local events resolve locally. Wave Collapse final selection is a global cinematic. Theme changes vocabulary, not mechanics. Theme must not hide causality.

## Implementation families (choose, do not blanket)

1. SVG: sigils, line work, icons, occult glyphs, overlays, repeated light effects
2. R3F geometry / particles: spatial paths, Node fields, card-world interaction
3. Shaders / post: quantum distortion, wave, singularity-class, Collapse theatrical tier

UX Lead owns comprehension. LookDev owns visual language. Engineering owns feasibility. Astra synthesizes art direction.

Selection criteria: comprehension, spatial causality, theatrical tier, thematic fit, repeated use, performance, accessibility, cost, competitive contribution.

## Effect-animation Assets are REFERENCES ONLY

Files in `assets/effect_animations/` must not be copied, embedded, shipped, traced, or presented as authored 0uroboros effects.

Filename tags (`occult`, `quantum`, `destroy`, `fire`, `big-attack`) are art-direction metadata. They do not create mechanics. Untagged refs may apply anywhere UX + LookDev + Astra judge the motion language appropriate.

Registry: `EFFECT_REFERENCE_REGISTRY.json`. Inspect the file. Do not infer the look from the filename alone.

## Code technique references

V2 `06_RESOURCE_LIBRARY.md` 3JS section is technique study: EffectComposer, GeometryPainter, ScanEffect, Origami, particles, singularity, liquid-wave. Study approach. Do not copy wholesale. Follow license. Store provenance on each implemented effect.

## Quality loop

Creator ≠ sole grader. Critique uses running-game evidence (idle, hand, drag, deploy, reveal, Card effect, Location effect, Node Power, Collapse, Draft). Weak incrementalism (glow, radius, random particles) cannot score high if composition is weak.

Competitive bar: Marvel Snap videos and Examples of Good in the Resource Library. Compare to the comps, not only yesterday's build.
