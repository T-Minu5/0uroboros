# Effects, Animation, and Reference Policy

Effects first explain what the game did; then they create thematic/emotional payoff.

## Reference animation assets
Assets may contain many animation/effect references. **None may be used directly in production.** Do not embed, ship, copy frames, or trace them into near-identical assets.

Use them to learn motion, timing, buildup, geometry, field/energy behavior, and thematic association.

## Filename tags
Tags such as `occult`, `quantum`, or other theme terms are intentional matching guidance. They do not define mechanics. Untagged references may be used wherever art direction fits.

## Production media
Authored SVG: sigils, sacred/technical geometry, line diagrams, icon animation, symbolic construction.

R3F/Three.js: source-target paths, physical card/world motion, particles, Node/world effects.

Shaders/post: wave deformation, interference, distortion, singularity, probability fields, high-tier Collapse/game-end moments.

Combinations are allowed when coherent and performant.

## Effect grammar
When applicable:
`SOURCE -> ACTIVATION -> PATH -> TARGET -> REACTION -> RESULT`

Drain: source activates -> path to opponent Data Center -> target reacts -> integrity changes.

Restore: source activates -> stabilizing/reconstructive path -> Data Center -> integrity changes.

Probability: source Node visibly loses -> effect travels -> destination gains -> values interpolate.

Draw: subtle Deck -> Hand.

Action: source -> Action resource response.

## Theatrical tiers
Tier 1 micro: Draw, Action, Crypto, small Power.
Tier 2 tactical: Drain, Restore, movement, probability transfer, reveal, Trash.
Tier 3 major: Node winner, major Location reward, Data Center destruction.
Tier 4 cinematic: Wave Collapse final selection, game-ending event.

## Marvel Snap — sequencing
Study staggered resolution, one active event, source before consequence, readable beat, active-location focus, anticipation. Transfer sequencing only, not skin.

## Hearthstone — motion weight
Study card physicality, windup, acceleration, contact/arrival, follow-through, settle/recovery, hover/idle tactility. Transfer motion craft only, not theme/frames/iconography.

## Three.js / code references
Resource library may include EffectComposer, GeometryPainter-like, scan, particle, origami/fold, singularity, wave/liquid techniques. Inspect actual technique where possible, learn mechanism, create original 0uroboros implementation, respect licensing.

## Wave Collapse
Signature presentation must preserve deterministic Node story while escalating final probabilistic selection. Candidate vocabulary: active-Node isolation, field quieting, probability rings, wave displacement, inward particles, singularity, controlled chromatic separation, selected-Node breakthrough, localized lighting, controlled post.

Do not stack everything; readability remains required.

## Provenance
For implemented effects record gameplay event, reference assets, code technique references, extracted principle, theme tags, chosen medium, original files, UX intent, visual intent, performance notes.
