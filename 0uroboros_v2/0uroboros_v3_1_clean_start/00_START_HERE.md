# 0uroboros V3.1 Clean-Start Project Pack

## Purpose
This is the ground-up context package for Astra and all specialists entering a fresh repository with no prior conversation memory.

It separates:
1. **Canonical game truth** — rules and approved behavior.
2. **Product / UX contract** — approved interaction and information architecture.
3. **Creative direction / references** — how the game should look, feel, move, and use source material.
4. **Development guidance** — how Astra may organize specialists, implementation, iteration, testing, and review.

Creative references never override canonical rules.

## Core operating principle
**Mel owns the game and approved product intent. Astra owns the development strategy. Specialists own domain judgment. Deterministic tests protect deterministic truth.**

## Fresh-project rule
Do not assume any previous implementation, harness, visual design, folder structure, or model context exists.

Historical files added later are evidence unless explicitly promoted into the authority hierarchy.

## Human checkpoint
Astra should do substantial work and stop when there is enough coherent, functioning product for Mel to judge, approximately an **80% direction-confidence checkpoint**.

This is not a claim that the game is 80% complete.

No checkpoint is valid if approved rules changed, repeated Cycles do not work, Draft/Wave Collapse progression is broken, approved UX structure is violated, or the current build has not been evaluated against first-party and competitive references.
