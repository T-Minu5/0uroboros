# Crypto

The buying resource. It only exists for the current [[Cycle]]'s [[Draft]].

## Sources
- [[Crypto card|Crypto cards]] auto-resolving at the start of the Draft
- "+N Crypto" effects during the Cycle
- Circuit Rewards such as Quantum dividend or Lil help

## Uses
- Buying [[Market]] cards (price = card `cost`)
- "Pay N Crypto" costs on Choice options

Held as the [[Wallet]] amount. Resets to 0 each Cycle; unspent Crypto is lost.
