# Action (removed)

The former Runtime **deployment resource** has been removed from the game.

- Characters (and Solar-monks) deploy freely; there is no Action budget or spend.
- `gainActions` effects and “+N Action(s)” printed text are gone from content and the engine.
- Do not confuse this with the **CardClass** “Action” subtype (still in use for card frames and Location conditions).
