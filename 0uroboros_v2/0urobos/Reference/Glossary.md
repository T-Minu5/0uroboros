## Retired or renamed
| Old word | Now | Why |
| --- | --- | --- |
| Heal (card) | **Restore** | Shorter card text |
| Restore (server), Restore N to | **Repair** | Restore now means card Power |
| Give N Victory Points | **+N VP** | Shorter card text |
| Gain 1 X into … draw pile top | **Gain a X on top of your deck** | Shorter card text |
| Primary-only drain | **Available** or **Both** | Primary target dropped from the editor |
| Data Center | **Server** | Old log wording |
| Node weights / percentages, probability | Removed | Location-count control replaced weighted selection |
| +Draft effects | **Node Power transfer** (Push / Pull) | +1/+2/+3 → 1/2/3 Power |
| `power` card tag | **Hacker** class | Avoids clashing with numeric Power |
| `encryptedVolume` | **Volume** class | Normalized naming |
| Shift N power | Push / Pull / Push or pull | Transfer wording |
| Both players | **Both** (Who label) | Shorter editor labels |

## Easily confused
- **Node vs Location** — the slot vs the content on it.
- **Card Power vs Node Power** — one card vs a side's total at a Node.
- **Trash vs Destroyed** — shared and recoverable vs per-owner.
- **Restore vs Reset vs Repair** — heal a card / set a card to printed / heal a Server.
- **Wallet zone vs Wallet amount** — the Crypto cards vs the money.
- **Runtime (phase) vs Runtime (card class)** — the deploy phase vs a Base class of Draft-only Characters.
- **Action (resource) vs Action (card class)** — the deploy resource vs a Base class of Characters.
